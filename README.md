# LOMBOK - Holistic Health & Wellness Platform

A modern, responsive web platform dedicated to holistic health education and wellness content. LOMBOK brings together articles, insights, and information about mindfulness, wellness, and balanced living.

## 📋 Overview

LOMBOK is a beautifully designed website focused on promoting holistic health practices and spreading awareness about wellness. The platform features a clean, minimalist interface with engaging content sections dedicated to holistic health, mindfulness, and overall well-being.

## ✨ Features

- **Responsive Landing Page**: Eye-catching hero section with navigation menu
- **Articles Section**: Showcase of the latest wellness and mindfulness articles
- **Multiple Content Pages**: Organized sections for navigation (About, Articles, Subscribe)
- **Modern Design**: Clean aesthetics with professional typography and imagery
- **Interactive Navigation**: Hover effects and smooth user experience
- **Image Integration**: High-quality unsplash images for visual appeal

## 🛠️ Technology Stack

- **HTML5**: Semantic markup structure
- **CSS3**: Advanced styling and responsive design
- **Remixicon**: Icon library for enhanced UI elements
- **Google Fonts (Montserrat)**: Professional typography

## 🚀 Installation & Setup

1. **Clone or Download the Project**

   ```bash
   git clone <repository-url>
   cd Lombok
   ```

2. **No Installation Required**
   - This is a static website with no backend dependencies
   - All external resources are loaded via CDN
